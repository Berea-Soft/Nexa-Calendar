# Support

## Getting Help

We want everyone to have a great experience with Nexa-Calendar. Here's how to
get help:

### Documentation

- [API Documentation](https://nexa-calendar.vercel.app)
- [Example App](https://nexa-calendar.vercel.app/demo2)
- [GitHub Issues](https://github.com/Berea-Soft/Nexa-Calendar/issues)

### Community

- **GitHub Discussions**: Ask questions and share ideas at https://github.com/Berea-Soft/Nexa-Calendar/discussions
- **Stack Overflow**: Tag your questions with `nexa-calendar`

### Reporting Issues

Before opening an issue:

1. Search existing issues to avoid duplicates
2. Include your environment details (OS, Node version, package versions)
3. Provide a minimal reproduction or code sample
4. Use the issue template when available

Create an issue: https://github.com/Berea-Soft/Nexa-Calendar/issues

## Feature Requests

We welcome feature requests! Please:

- Search existing feature requests first
- Clearly describe the use case and problem
- Explain why this would benefit the library
- Be patient - we consider all requests carefully
